Política de privacidad

MenteXYZ Studio · vigente desde el 14 de octubre de 2026

Quién la usa

MenteXYZ Studio es una aplicación de uso personal del creador del canal de YouTube MenteXYZ. Solo accede a las cuentas de Google del propio canal, con la autorización explícita de su dueño. No tiene otros usuarios.

Qué datos usa y para qué

  • YouTube Data API (youtube.upload, youtube.force-ssl): subir los videos del canal en privado, sus subtítulos y su miniatura; programar su publicación; publicar el comentario del canal y consultar el estado de sus propios videos.
  • YouTube Analytics API (yt-analytics.readonly, youtube.readonly): leer las estadísticas del propio canal (vistas, horas de reproducción, suscriptores) para un informe semanal interno.
  • Gmail API (gmail.modify, gmail.send): leer los correos del canal para clasificarlos con reglas fijas (estafas, suplantación, correos peligrosos), etiquetarlos y moverlos a la Papelera de Gmail (de donde se recuperan durante 30 días), y enviar avisos cortos al correo personal del dueño. La aplicación nunca borra correos de forma definitiva.

Dónde quedan los datos

Todo se procesa en el computador del dueño del canal. Las autorizaciones de Google (tokens) se guardan cifradas con la protección de datos de Windows. Del correo solo se guardan datos de clasificación (dominio del remitente, categoría, nivel de riesgo y el asunto abreviado), nunca el contenido de los mensajes. El contenido de los correos no se envía a modelos de inteligencia artificial ni a ningún servicio externo.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se transfieren salvo a las propias APIs de Google para realizar las acciones descritas.

Uso limitado

El uso y la transferencia de la información recibida de las APIs de Google por MenteXYZ Studio cumplen la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso y borrar los datos

El dueño puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de acceder a la cuenta; los datos locales se borran eliminando la carpeta de estado de la aplicación en su computador.
